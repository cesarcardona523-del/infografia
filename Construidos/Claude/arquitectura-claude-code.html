Taxonomía de Comandos para LLMs

Estructurar las interacciones mediante pseudo-comandos reduce la ambigüedad, fuerza el razonamiento estructurado (Chain-of-Thought) y maximiza la precisión en modelos conversacionales.

1. Contexto e Inicialización

/role Define el experto a simular y su tono base.
/context Inyecta background crítico del negocio o proyecto.
/rules Establece restricciones estrictas (negativas o positivas).
/format Define la estructura de salida (Markdown, JSON, Tabla).
/steps Fuerza un proceso procedimental paso a paso.

2. Razonamiento y Análisis

/think Obliga al modelo a imprimir su razonamiento antes de responder.
/critique Instruye una autoevaluación severa de la respuesta anterior.
/compare Genera matriz estructurada de pros, contras y trade-offs.
/simulate Ejecuta escenarios hipotéticos "What-if" con múltiples variables.
/breakdown Descompone un problema complejo en sub-tareas atómicas.

3. Ingeniería y Código

/refactor Optimiza código reduciendo complejidad ciclomática.
/debug Rastrea flujos de ejecución para aislar errores o leaks.
/doc Genera JSDoc, Docstrings o Swagger automáticamente.
/test Escribe pruebas unitarias cubriendo edge cases específicos.
/explain Detalla la arquitectura de una función línea por línea.

4. Datos y Visualización

/extract Extrae entidades de texto libre hacia formato JSON o CSV.
/mermaid Escribe código Mermaid.js para renderizar diagramas.
/aggregate Resume grandes volúmenes identificando tendencias.
/clean Normaliza formatos de fecha, moneda y detecta nulos.
/sql Traduce lenguaje natural a consultas SQL optimizadas.

5. Refinamiento Editorial

/expand Profundiza verticalmente en un punto específico del texto.
/simplify Adapta el nivel de lectura (ej. de académico a divulgativo).
/tone Gira el estilo hacia formal, persuasivo, técnico o empático.
/iterate Genera 'N' variaciones semánticas del mismo concepto.
/translate Traduce conservando jerga técnica y modismos nativos.

Arquitectura del Mega-Prompt

1 <system> Rol, Contexto y Reglas
↓
2 <input> Datos en bruto o solicitud del usuario
↓
3 <commands> Instrucciones operativas (/think, /format)
↓
4 <output> Respuesta precisa y determinista
