6 Errores Comunes con GROUP BY

Guía Técnica de SQL · Diagnóstico y Soluciones
SQL Optimization
1
Columnas no agrupadas Seleccionar columnas que no están en el GROUP BY ni agregadas.
✕ Incorrecto
SELECT Ciudad, Nombre, COUNT(*) 
FROM Clientes GROUP BY Ciudad;
✓ Correcto
SELECT Ciudad, COUNT(*) 
FROM Clientes GROUP BY Ciudad;
2
Omitir funciones de agregación Intentar resumir datos planos sin usar funciones como SUM o AVG.
✕ Incorrecto
SELECT Dept, Salario 
FROM Empleados GROUP BY Dept;
✓ Correcto
SELECT Dept, SUM(Salario) AS Total 
FROM Empleados GROUP BY Dept;
3
Filtrar agregados con WHERE WHERE actúa antes de agrupar; para filtrar grupos se usa HAVING.
✕ Incorrecto
FROM Emp GROUP BY Dept 
WHERE COUNT(*) > 5;
✓ Correcto
FROM Emp GROUP BY Dept 
HAVING COUNT(*) > 5;
4
Agrupar columnas de más Agregar demasiadas dimensiones fragmenta innecesariamente el resultado.
✕ Exceso de Grupos
GROUP BY Año, Mes, Dia, Hora_Exacta, Producto;
✓ Nivel Óptimo
GROUP BY Año, Mes, Producto;
5
Ignorar datos duplicados El error de conteo suele deberse a registros duplicados previos en la tabla.
✕ Sin Validación
SELECT *, COUNT(*) FROM Tabla 
GROUP BY Clave;
✓ Con Auditoría previa
SELECT Clave, COUNT(*) FROM Tabla
GROUP BY Clave HAVING COUNT(*) > 1;
6
No filtrar antes de agrupar Agrupar la tabla completa cuando WHERE podría descartar filas irrelevantes desde antes.
✕ Agrupa Todo
SELECT Dept, COUNT(*) FROM Empleados
GROUP BY Dept;
✓ Filtra Primero
SELECT Dept, COUNT(*) FROM Empleados
WHERE Activo = 1 GROUP BY Dept;
💡 Regla de Oro: Menos columnas innecesarias y uso correcto de cláusulas garantizan consultas limpias y eficientes.
