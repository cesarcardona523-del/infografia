6 Errores Comunes con GROUP BY

SQL Optimization
1
Columnas no agrupadas: fuera del GROUP BY o sin agregar.
✕ Incorrecto
SELECT Ciudad, Nombre, COUNT(*)
FROM Clientes GROUP BY Ciudad;
✓ Correcto
SELECT Ciudad, COUNT(*)
FROM Clientes GROUP BY Ciudad;
2
Sin función de agregación: datos planos sin SUM/AVG.
✕ Incorrecto
SELECT Dept, Salario
FROM Empleados GROUP BY Dept;
✓ Correcto
SELECT Dept, SUM(Salario) AS Total
FROM Empleados GROUP BY Dept;
3
WHERE en vez de HAVING: WHERE no filtra agregados.
✕ Incorrecto
FROM Emp GROUP BY Dept
WHERE COUNT(*) > 5;
✓ Correcto
FROM Emp GROUP BY Dept
HAVING COUNT(*) > 5;
4
Agrupar de más: demasiadas dimensiones fragmentan el resultado.
✕ Exceso de grupos
GROUP BY Año, Mes, Dia, Hora_Exacta, Producto;
✓ Nivel óptimo
GROUP BY Año, Mes, Producto;
5
Duplicados ignorados: inflan el conteo sin validar antes.
✕ Sin validación
SELECT *, COUNT(*) FROM Tabla
GROUP BY Clave;
✓ Con auditoría previa
SELECT Clave, COUNT(*) FROM Tabla
GROUP BY Clave HAVING COUNT(*) > 1;
6
No filtrar antes: agrupa todo en vez de filtrar primero.
✕ Agrupa todo
SELECT Dept, COUNT(*) FROM Empleados
GROUP BY Dept;
✓ Filtra primero
SELECT Dept, COUNT(*) FROM Empleados
WHERE Activo = 1 GROUP BY Dept;
💡 Regla de oro: menos columnas innecesarias y uso correcto de cláusulas garantizan consultas limpias y eficientes.
