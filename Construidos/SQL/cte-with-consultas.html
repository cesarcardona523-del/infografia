CTE (WITH): la Forma Moderna de Ordenar tus Consultas

Qué problema resuelve frente a las subconsultas anidadas

Qué es un CTE
Una tabla temporal con nombre, definida con WITH, que existe solo durante esa consulta y se puede reutilizar dentro de ella.
WITH resumen AS ( SELECT categoria, SUM(monto) AS total_ventas FROM ventas GROUP BY categoria ) SELECT categoria, total_ventas FROM resumen WHERE total_ventas > 1000
Antes · Subconsulta anidada
SELECT categoria, total_ventas FROM ( SELECT categoria, SUM(monto) AS total_ventas FROM ventas GROUP BY categoria ) AS resumen WHERE total_ventas > 1000
Se lee de adentro hacia afuera
Ahora · CTE
WITH resumen AS ( SELECT categoria, SUM(monto) AS total_ventas FROM ventas GROUP BY categoria ) SELECT categoria, total_ventas FROM resumen WHERE total_ventas > 1000
Se lee de arriba hacia abajo, por pasos
Se puede encadenar
Un CTE se puede reutilizar varias veces en la misma consulta, y se pueden encadenar varios, cada uno con su propio nombre.
WITH resumen AS (SELECT categoria, SUM(monto) AS total_ventas FROM ventas GROUP BY categoria), top_categorias AS (SELECT * FROM resumen WHERE total_ventas > 1000) SELECT * FROM top_categorias
Mismo resultado, más legible
Reutilizable dentro de la misma consulta
Se pueden encadenar varios CTEs por pasos
