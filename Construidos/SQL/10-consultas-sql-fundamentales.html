10 Consultas SQL Imprescindibles

Dominar estas estructuras te permite extraer, transformar y analizar datos eficientemente, siendo la base de procesos ETL, Business Intelligence y Data Science.

Guía de Referencia
1
SELECT + WHERE
Filtra información de una tabla basándose en una condición lógica específica.
SELECT nombre, salario
FROM empleados
WHERE salario > 5000;

ORDER BY
Ordena los resultados devueltos de forma ascendente (ASC) o descendente (DESC).
SELECT nombre, salario
FROM empleados
ORDER BY salario DESC;

GROUP BY
Agrupa filas para aplicar métricas de agregación (COUNT, SUM, AVG, MAX).
SELECT depto, COUNT(*) AS tot
FROM empleados
GROUP BY depto;

INNER JOIN
Combina y retorna solo los registros que tienen coincidencia en ambas tablas.
SELECT c.nom, p.fecha
FROM clientes c
INNER JOIN ped p ON c.id = p.c_id;

LEFT JOIN
Retorna todos los registros de la tabla izquierda, incluso sin coincidencia.
SELECT c.nom, p.fecha
FROM clientes c
LEFT JOIN ped p ON c.id = p.c_id;

6
HAVING
Filtra resultados basándose en una función de agregación (actúa tras el GROUP BY).
SELECT depto, COUNT(*)
FROM empleados GROUP BY depto
HAVING COUNT(*) > 5;

CASE WHEN
Implementa lógica condicional (IF-THEN-ELSE) directamente en la consulta.
SELECT nom, CASE
  WHEN sal > 6k THEN 'Alto'
  ELSE 'Normal' END AS cat
FROM emp;

8
ROW_NUMBER()
Window function que asigna un número secuencial a las filas particionadas.
SELECT nom,
ROW_NUMBER() OVER(
  ORDER BY sal DESC
) AS rank FROM emp;

9
CTE (WITH)
Crea conjuntos de resultados temporales para hacer consultas legibles y reusables.
WITH cte AS (
  SELECT id, SUM(tot) AS t
  FROM ped GROUP BY id
) SELECT * FROM cte;

SUBCONSULTAS
Anida una consulta dentro de otra para usar su resultado dinámicamente.
SELECT nom, sal FROM emp
WHERE sal > (
  SELECT AVG(sal) FROM emp
);
