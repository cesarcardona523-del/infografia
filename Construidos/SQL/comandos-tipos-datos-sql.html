Comandos y Tipos de Datos en SQL

Un mismo script recorre las 4 familias de comandos — DML, DDL, DCL y TCL — más los tipos de datos ANSI que los sostienen, comunes a la mayoría de motores SQL.

gestion_clientes.sql
-- DDL: crear la estructura
CREATE TABLE Clientes (
  Id INT PRIMARY KEY, Nombre VARCHAR(100),
  FechaAlta TIMESTAMP, Saldo DECIMAL(10,2)
);
-- DML: manipular los datos
INSERT INTO Clientes VALUES
  (1, 'Ana Ruiz', CURRENT_TIMESTAMP, 1500.00);
SELECT Nombre, Saldo FROM Clientes WHERE Saldo > 1000;
-- DCL: controlar el acceso
GRANT SELECT ON Clientes TO Analista;
START TRANSACTION; -- TCL
  UPDATE Clientes SET Saldo = Saldo - 200 WHERE Id = 1;
COMMIT;
