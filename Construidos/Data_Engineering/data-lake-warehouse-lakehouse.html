Arquitectura de Datos

Data Lake vs Data Warehouse vs Data Lakehouse

Mismo objetivo — convertir datos en información útil — pero tres formas muy distintas de guardarlos, estructurarlos y usarlos.

Data Lake = guardás todo. Data Warehouse = entendés y organizás. Data Lakehouse = ambas cosas, a la vez.
1
Data Lake
El Lago
Datos crudos Formato original
Guarda todo tipo de datos — estructurados, semiestructurados y no estructurados (SQL, CSV, JSON, PDF, imágenes, video).
Escalable y económico — desde GB hasta PB, sin imponer estructura al momento de guardar.
Los datos se transforman cuando se necesitan — no antes de guardarlos (schema-on-read).
Se consulta con motores como Spark, Presto o Athena, directamente sobre los archivos.
Ideal paraExplorar datos, proyectos de IA/ML, logs, IoT — cuando aún no sabés qué preguntas vas a responder.
2
Data Warehouse
El Depósito Ordenado
Datos limpios Listo para analizar
Guarda datos ya estructurados y preparados — el modelado se hace antes de cargar (schema-on-write).
Optimizado para consultas rápidas — pensado desde el diseño para reportes y dashboards.
Gobernado, confiable y consistente — una única versión de la verdad para el negocio.
Ejemplos típicos: Snowflake, BigQuery, Redshift, Synapse.
Ideal paraReportes, dashboards ejecutivos, indicadores y consultas que necesitan respuestas rápidas y consistentes.
3
Data Lakehouse
La Casa Inteligente
Zona flexible + zona estructurada
Combina lo mejor de los dos: la flexibilidad del lago + la estructura del depósito, en el mismo lugar.
Rendimiento alto para análisis y machine learning, sin duplicar los datos en dos sistemas.
Un solo sistema, dos zonas — guarda datos crudos y estructurados juntos, sin duplicar infraestructura.
Ejemplos típicos: Databricks (Delta Lake), Apache Iceberg.
Ideal paraOrganizaciones que quieren escalar, usar IA/ML y BI al mismo tiempo, sin duplicar datos ni sistemas.
Data Lake: guardás todo primero, entendés después.
Data Warehouse: entendés y organizás, para analizar rápido.
Data Lakehouse: guardás y entendés, para analizar rápido y a gran escala.
