# Contrato de Datos (YAML Schema)
data_contract_version: "1.2.0"
schema:
  - name: id_cliente
    type: string
    constraints: [not_null, unique]
  - name: monto
    type: decimal
    constraints: [not_null, positive]
El contrato de datos es la frontera: si el productor rompe el schema, la ingesta falla rápido y de forma visible — en vez de propagar datos corruptos silenciosamente hasta Gold.
Bronze Ingesta casi en tiempo real vía streaming o CDC — prioriza velocidad sobre limpieza.
Silver Procesamiento por micro-lotes cada pocos minutos — ya validado y deduplicado.
Gold Actualización programada (batch) alineada al ritmo real de consumo del negocio.
