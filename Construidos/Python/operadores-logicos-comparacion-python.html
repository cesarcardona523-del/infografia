Los mismos 6 operadores que en SQL, pero con reglas propias — más identidad (is) y pertenencia (in), sin equivalente directo en SQL.

Diferencia clave con SQL: en Python < > <= >= también aplican a texto — compara cadenas de forma lexicográfica (alfabética/Unicode): 'ana' < 'bruno' es True.

Potenciado: identidad y pertenencia

is / is not

Compara identidad (mismo objeto en memoria), no valor. Uso real: x is None.

in / not in

Comprueba pertenencia a una lista, string, set o dict. Sin equivalente de una palabra en SQL.

Intersección

and Ambas condiciones

Cortocircuito: si la primera es falsy, ni evalúa la segunda — devuelve esa; si no, devuelve el valor de la segunda.

Ejemplo
if pais == 'Colombia' and edad >= 30:
