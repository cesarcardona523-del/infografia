10 Términos Esenciales de Ciencia de Datos y Machine Learning

Un glosario de referencia rápida — el vocabulario mínimo para entender cualquier conversación técnica sobre modelos.

Dataset

Instancia particular de datos usada para análisis o modelado en un momento dado.

Tipos: numérico, categórico, texto, imagen, voz y video. Para proyectos iniciales, lo más común es un dataset numérico en formato CSV.
Data Wrangling

Convertir datos crudos en una forma ordenada, lista para el análisis.

Incluye: importación, limpieza y estructuración, procesamiento de texto, manejo de fechas y de valores faltantes — la base de todo el preprocesamiento.
Outliers

Puntos muy distintos al resto del dataset; se detectan con boxplots.

Riesgo: pueden degradar el poder predictivo de un modelo. Método avanzado de detección: RANSAC.
Supervised Learning

Aprende la relación entre variables y un target ya conocido.

Continuo → regresión (Lineal, KNR, SVR). Discreto → clasificación (Logística, SVM, árboles de decisión).
Unsupervised Learning

Explora la estructura de datos no etiquetados, sin variable objetivo.

Ejemplo: K-means clustering agrupa observaciones similares sin conocer las categorías de antemano.
Reinforcement Learning

Un agente aprende por prueba y error, usando recompensas y castigos.

Ciclo: el agente actúa sobre el entorno; el entorno responde con un nuevo estado y una recompensa.
Cross-validation

Evalúa el modelo repitiendo el entrenamiento en k particiones distintas.

K-fold: el proceso se repite k veces rotando el bloque de test; el resultado final promedia el desempeño de todas las particiones.
Bias-Variance Tradeoff

El equilibrio entre subajuste (alto sesgo) y sobreajuste (alta varianza).

Objetivo: ajustar la complejidad del modelo hasta el punto de capacidad óptima, donde el error de generalización es mínimo.
PCA

Reduce la dimensionalidad conservando la mayor varianza posible.

Cómo funciona: transforma variables correlacionadas en componentes principales no correlacionados, ordenados por varianza explicada.
Regularización (L1/L2)

Penaliza coeficientes grandes para reducir el sobreajuste del modelo.

L1 (Lasso): puede llevar coeficientes exactamente a cero (selección de variables). L2 (Ridge): los reduce sin eliminarlos.
Por qué importa — este vocabulario aparece en casi cualquier discusión técnica de un proyecto de machine learning; no dominarlo dificulta evaluar si un modelo está bien construido.
