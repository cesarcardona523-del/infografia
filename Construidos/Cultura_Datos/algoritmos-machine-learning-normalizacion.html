¿Qué Algoritmos Requieren Normalización?

Algoritmo ¿Normalización? Método Recomendado
Regresión Lineal / Logística Sí (Regularización) Z-Score
K-Means & KNN Sí (Distancias) Z-Score / Min-Max
Support Vector Machines (SVM) Sí (Optimización) Z-Score
Redes Neuronales (Deep Learning) Sí (Gradientes) Min-Max
PCA (Reducción de Dimensionalidad) Sí (Varianza) Z-Score
Árboles de Decisión / Random Forest No requerido No aplica

Cómo Transforma Cada Técnica los Datos

Z-Score (Estandarización)

Centra los datos en media 0 y desviación 1 — ideal para SVM, regresión y PCA.

Min-Max Normalization

Comprime todo al rango fijo [0,1] — clave para redes neuronales.

Robust Scaling

Usa mediana e IQR — el outlier (verde) no arrastra la escala del resto.

Log / Box-Cox Transform

Reduce la asimetría de colas largas antes de escalar el resto.
