Glosario de IA Agéntica para Líderes

Conceptos clave de arquitectura, despliegue y gobernanza

Guía de Referencia Técnica

Fundamentos

Agente de IA Software que razona y ejecuta tareas autónomas usando herramientas (APIs, DBs), más allá de solo generar texto.
IA Agéntica Ecosistema donde múltiples agentes interactúan, colaboran y resuelven problemas sin supervisión humana constante.
Autonomía Nivel de capacidad técnica y de permisos que posee un agente para tomar decisiones por sí solo.

Arquitectura

Orquestación Patrón de diseño (ej. LangGraph) para gestionar el estado, la memoria y el enrutamiento de tareas.
Patrón Supervisor Topología donde un agente maestro evalúa intenciones, planifica y delega subtareas a agentes ejecutores.
Multiagente Sistema distribuido donde roles (Researcher, Coder, Reviewer) colaboran iterativamente para un output.

Funcionamiento

Reasoning (Razonamiento) Proceso mediante el cual el LLM evalúa caminos (ej. Chain-of-Thought) antes de ejecutar una acción.
Tool Use (Herramientas) Capacidad crítica de invocación de funciones que permite al agente interactuar con CRMs o la web.
Memoria Persistente Almacenamiento (bases de datos vectoriales) del historial para mantener la coherencia a largo plazo.

Seguridad & Control

Guardrails Filtros de validación estrictos que limitan el espacio de acción, respuesta y acceso a datos.
Human-in-the-Loop (HITL) Patrón que interrumpe la ejecución autónoma para requerir aprobación humana explícita en acciones críticas.
Escalación (Handoff) Fallback donde el agente transfiere el control a un humano al detectar un error o límite.

Despliegue & MLOps

Observabilidad Monitorización de trazas, tokens y latencia para depurar y optimizar flujos agénticos en tiempo real.
Inferencia y Tokens El cómputo donde el LLM genera respuestas. Los tokens (fragmentos) dictan el coste y velocidad.
Rastro de Auditoría Registro inmutable (logs) de cada API call, razonamiento y acción ejecutada para compliance.
