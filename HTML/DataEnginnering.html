Data Engineering Competency Matrix

Mapa de Habilidades: Data Engineering

Ecosistema técnico modular requerido para diseñar, construir y escalar infraestructura de datos moderna.

1. Fundamentos
Python SQL Linux CLI Git / VCS Shell Scripting
La base no negociable: sin esto, cualquier pipeline se vuelve frágil y difícil de mantener en el tiempo.
2. Ingesta & Streaming
Apache Kafka REST APIs CDC (Debezium) Batch Processing WebSockets
Cómo entran los datos: en tiempo real vía streaming, o en lotes programados según la urgencia del caso.
3. Transformación
dbt (Data Build Tool) Advanced SQL ELT Patterns Data Modeling
Convertir datos crudos en modelos analíticos confiables, con lógica versionada y testeable.
4. Procesamiento & Big Data
Apache Spark Apache Flink Databricks Hive / Trino
Motores distribuidos para volúmenes que no caben — ni en memoria ni en tiempo razonable — en una sola máquina.
5. Arquitectura de Datos
Data Warehouse Data Lake Lakehouse Object Storage
Dónde vive el dato según su propósito: normalizado, crudo, o ya modelado para consumo directo.
6. Orquestación
Apache Airflow Dagster Prefect Cron / Scheduling
Quién decide cuándo corre cada tarea, en qué orden, y qué hacer si algo falla en el camino.
7. Cloud & Infraestructura
AWS / GCP / Azure Docker Kubernetes Terraform (IaC)
La capa que hace reproducible y escalable todo lo anterior, sin depender de un servidor físico.
8. Calidad & Observabilidad
Data Quality Great Expectations Data Lineage Monitoring
Detectar un dato roto antes de que llegue a un dashboard ejecutivo, no después.
9. IA & Data Engineering
Vector Databases RAG Pipelines Feature Stores MLOps Integration
El nuevo frente: preparar datos no solo para dashboards, sino para alimentar modelos y agentes.
El diseño de arquitecturas de datos no es lineal: es un ecosistema integrado de habilidades y herramientas.
