Algoritmos de Machine Learning y Normalización de Datos

¿Qué Algoritmos Requieren Normalización?

Algoritmo ¿Normalización? Método Recomendado
Regresión Lineal / Logística Sí (Regularización) Z-Score
K-Means & KNN Sí (Distancias) Z-Score / Min-Max
Support Vector Machines (SVM) Sí (Optimización) Z-Score
Redes Neuronales (Deep Learning) Sí (Gradientes) Min-Max
PCA (Reducción de Dimensionalidad) Sí (Varianza) Z-Score
Árboles de Decisión / Random Forest No requerido No aplica

Guía Rápida de Decisión por Escenario

Situación de los Datos Técnica Ideal
Datos con distribución normal (Gaussiana) Z-Score Normalization
Presencia de outliers severos en el dataset Robust Scaling
Redes Neuronales (activaciones acotadas) Min-Max (0 a 1)
Variables altamente sesgadas (asimetría) Log / Box-Cox Transform
Modelos basados en distancias (Euclideana) StandardScaler
Ensembles basados en árboles (XGBoost, RF) Sin transformación
Data Preprocessing Machine Learning Pipeline Feature Scaling
